Pushback Creator App for Mac
Unsigned build — not from the Mac App Store

This .app is unsigned. macOS will warn that it is from an unidentified
developer. That is expected. Only install it if you trust the person
who sent this file.

Install

1. Unzip the download (double-click the .zip in Finder).
2. Drag Pushback Creator App.app (or FSG_PushbackCreatorApp.app) into
   the Applications folder.
3. Open Applications and start the app.

If macOS blocks it (“cannot be opened because the developer cannot be
verified” or similar)

1. Open System Settings.
2. Go to Privacy & Security.
3. Scroll to Security.
4. Click Open Anyway for this app, then confirm.

You can also Control-click the app in Applications and choose Open,
then confirm.

Do not run the app from inside the .zip, from Downloads, or from a
cloud folder (Google Drive, iCloud Desktop, and similar). Copy it to
Applications first.
